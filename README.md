# Sitio web — Claudia Elena Tovar González

Sitio estático listo para publicar con GitHub Pages.

## Archivos
- `index.html` — página principal con información profesional y las dos imágenes proporcionadas.
- `blog-ansiedad.html` — artículo informativo sobre ansiedad y estrés.
- `blog-duelo.html` — artículo informativo sobre duelo y pérdidas.
- `styles.css` — diseño responsive.
- `images/consultorio.jpg` y `images/servicios.jpg` — imágenes proporcionadas.

## Publicación
1. Crear/iniciar sesión en GitHub.
2. Crear un repositorio público, por ejemplo `terapias-psicologicas`.
3. Subir todos estos archivos y la carpeta `images`.
4. En Settings → Pages, seleccionar `Deploy from a branch`, branch `main`, folder `/root`.
5. Guardar y esperar la publicación.

Antes de publicar, conviene confirmar los datos de contacto, ubicación y cualquier texto profesional que deba aparecer en el sitio.
